# PCR-002: Rename Floty → Pepper, and the Pepper theme

- **Status:** Implemented
- **Date:** 2026-10-18
- **Plan version:** from 0.9 → to 0.10

## What changes and why
1. **Name.** The product is now called **Pepper** (it was the working name "Floty"). Everything uses the new name: what people see (wordmark, page titles, the 2-step login issuer, the `pepper.app/<business>` address hint), the docs and mockups, and the code (`@pepper/*` packages, database roles and names, cookie names, telemetry service names, Docker images). The domain `pepper.app` is display text only; it is not registered.
2. **Theme "A. Pepper green + chili accent"** (the user's pick) replaces raspberry:
   - `brand` is pepper green (actions, links, selection), neutrals lean green.
   - New `accent` / `accent-soft` / `on-accent` tokens: chili red, for the mark, Pepper's own voice (AI avatar, briefing) and highlights. **Never for status**: chili must not read as an error.
   - So that brand and status colors stay apart: `ok` ("done") moves from green to teal; `danger` becomes a deeper crimson and is always shown with an icon or text.
   - Per-staff calendar colors: green / coral / amber. The sample business color on the booking page moves from teal to plum, so a business color never looks like Pepper's own.

Decided by the user on 2026-10-18 (this session): rename everywhere; edit the first migrations in place instead of adding a rename migration (nothing is deployed; local dev databases are rebuilt once); teal "done", chili as an accent only, plum sample business; `pepper.app` in the address hint.

## Compatibility strategy
A clean rename before any deployment or pilot: no aliases, no rename migration. The only data affected is local development data, rebuilt with the existing migrations.

## Tests proving no regression
- Every existing suite stays green after the rename: lint, typecheck, unit (with the coverage gate), build, integration (Testcontainers, including the cross-tenant isolation suite at 100%), and Playwright E2E.
- `packages/ui` theme test: every text/background pair, now including `accent`, passes WCAG 2.2 AA in light and dark; `theme.css` matches `tokens.ts`.
- Mockup: `docs/mockups/checks/contrast.py` (now covering `accent`) and the prototype click-through.
- A search for "floty" in the repo finds only the notes that record the rename: this PCR, the CHANGELOG entry, STATUS and the one-time database rebuild note in `engineering/dev-setup.md`.
