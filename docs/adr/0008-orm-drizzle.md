# ADR-0008: Drizzle ORM and SQL migrations

- **Status:** Accepted (2026-10-16) · **Date:** 2026-10-16 · Resolves open decision D3

## Context
The data layer relies on Postgres features: row-level security policies, `SET LOCAL` per transaction, GiST exclusion constraints, `tstzrange`, and pgvector.

## Decision
Use Drizzle ORM in `packages/db` for typed queries, with migrations generated by drizzle-kit and hand-edited SQL where needed (RLS policies, exclusion constraints, extensions). All access goes through repositories that run inside a tenant-scoped transaction helper.

## Consequences
+ SQL-first and transparent; easy to use advanced Postgres features; light runtime.
− Fewer batteries than Prisma (e.g. studio, relations ergonomics); acceptable for our needs.
